# Análise de Vendas - Power BI

Dashboard de Vendas

## Descrição
Este projeto analisa o desempenho de vendas de diferentes produtos em diversas lojas pelo Brasil.  
Principais informações extraídas:  
- Faturamento total de R$99 milhões.  
- Produto mais vendido: iPhone.  
- Quantidade vendida por loja e por produto.  
- Faturamento mensal ao longo do período analisado.  
- Distribuição de vendas por produto em gráficos de pizza e barras.  

> Observação: Os dados utilizados são fictícios, criados para demonstrar a análise.

## Dataset
- Arquivo: `vendas(2).xlsx` 
- Fonte: Dados fictícios para demonstração.

## Principais Insights
- iPhone é o produto mais vendido, representando destaque no faturamento.  
- Algumas regiões concentram maior quantidade de vendas.  
- Tendência de faturamento mensal está relativamente estável com pequenas variações.

## Tecnologias Utilizadas
- Power BI  
- Excel (para o dataset)
